📌 Project Overview

This project is a simple responsive frontend website created for Tata Consultancy Services (TCS) using HTML and CSS.
The website contains:

Navigation Bar
Hero Section
Company Information
Services Section
Industry Categories
Footer with Social Media Links

The project is designed as a beginner-friendly frontend development practice project.
